# 11.1 — Escopo executável e objetivo da etapa

**Projeto:** ADM Libare (refatoração do admin + APIs do leitor)  
**Status:** Em execução contínua (MVP admin + Site + reader espelho entregues; cutover Flutter em andamento)

## Objetivo geral

Modernizar o ecossistema **Alexandria / Libare** substituindo o painel PHP (`adm-libares`) e preparando a desativação das APIs PHP do app leitor, sem quebrar dados legados nem o Flutter.

## Escopo executável (o que está dentro)

1. **Painel admin** (`frontend-admin`): React + Vite, UX Berry, listagens padronizadas, FormModals.
2. **API admin** (`/api/v1/**`): Kotlin/Spring, JWT, RBAC, multi-tenant por escola.
3. **Catálogo ebook:** livros, autores, categorias, seções home, acervos, comentários.
4. **Módulo Site:** CRUD Sites/autores/categorias/seções/comentários + espelho `api_sites.php` (Galileu).
5. **Comunidade:** usuários do app (leitores), edição de perfil (nome/email/telefone), status, acervo.
6. **Sistema:** escolas, equipe (`admin-users`), perfis/roles, auditoria.
7. **APIs leitor (espelho PHP):** `/api.php`, `/user_*.php`, `/api_sites.php` para o Flutter só trocar host.
8. **Deploy:** Docker Compose na VPS, domínio HTTPS, assets legados montados.

## Fora de escopo (explícito)

| Item | Motivo |
|------|--------|
| Jogos (`api_jogos.php`) | Deliberadamente adiado |
| Unificação completa schema `core` em produção | Branch/gancho Postgres separado; produção em `legacy` |
| App Flutter (código-fonte) nesta entrega | Só contrato de host/API |
| Notificações push / Configurações avançadas do PHP | Menus ainda não migrados |

## Objetivos por etapa (mensuráveis)

| Objetivo | Critério de sucesso |
|----------|---------------------|
| Isolar escolas | Admin de escola não vê dados de outra (exceto Super Admin) |
| RBAC | Permissões `resource.action` no JWT + Policy no backend |
| Paridade catálogo | CRUD admin sem depender de `manage_*.php` |
| Site no React | Grupo Site completo no menu |
| Leitor Kotlin | Smoke `api.php?method_name=home` retorna envelope `EBOOK_APP` |
| Operação | Deploy reproduzível via `deploy-vps.sh` |
