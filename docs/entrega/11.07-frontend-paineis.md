# 11.7 — Frontend, funcionalidades e painéis

## Stack frontend

- **React 18** + **TypeScript** + **Vite**
- **TanStack React Query** (cache/invalidate)
- **Framer Motion** (microinterações)
- UI compartilhada em `frontend-admin/src/shared/ui`
- Estado de auth: `AuthContext` + permissões no token/me

## Painéis / funcionalidades por módulo

### Dashboard
- 3 KPIs (livros, usuários, comentários)
- Tendência de comentários
- Top 5
- `DashboardAlertStrip` (atenção de catálogo; alerta “sem categoria” sem link enganoso)

### Catálogo
- CRUD completo com FormModal + Detail quando aplicável
- Upload capa/arquivo
- Filtro por acervo (livros)
- Toggle status (inclui perfil PROFESSOR)

### Site
- CRUD Sites (modal), autores, categorias, seções
- Moderação de comentários Site (delete)
- Professor: listagem + ativar/desativar Site

### Comunidade
- Usuários: criar, editar perfil (nome/email/telefone), status, acervo, excluir
- Comentários ebook: publicar/ocultar, excluir

### Sistema
- Escolas / Equipe / Perfis: FormModal (create/edit)
- Auditoria: overview Berry com refresh

## Componentes-chave

| Componente | Papel |
|------------|-------|
| `ListingPageShell` | Layout de página |
| `AdminListingSection` | Busca, filtros, DataTable, mobile cards |
| `*FormModal` + `*Form` | Cadastro/edição |
| `PermissionGate` | Esconde CTA sem permissão |
| `useAdminMutation` | Toast + invalidate padronizados |
| `useSelectedEntity` | Sync do item aberto no detalhe |
| `LegacyImage` | Capas/avatares com fallback |

## Qualidade de código front

- Typecheck: `npx tsc --noEmit`
- Sem `setSaving` manual nas pages (Fase 8 concluída)
- Filtros sincronizados com URL (`useAdminListFilters`)
