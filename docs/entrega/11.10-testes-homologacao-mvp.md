## Definição de MVP

**MVP entregue:** painel React completo para operação diária (catálogo, Site, comunidade, sistema) + backend Kotlin com segurança e deploy Docker.

**Pós-MVP imediato:** cutover Flutter + desligar Apache/PHP ebook/site + (opcional) jogos.
