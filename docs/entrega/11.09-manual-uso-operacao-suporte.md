# 11.9 — Manual de uso, operação e suporte

## Acesso ao painel

1. Abrir https://admin.alenxandriaglobaltec.com (ou localhost:5173).
2. Login com usuário da **Equipe** (não é o leitor do app).
3. Se for admin de escola, selecionar escola no topo quando solicitado.

**Lab seed:** `teste.admin` / `Admin@123`

## Operação por papel

### Super Admin / School Admin
- Gerencia catálogo, usuários, Site (se permitido), equipe/perfis (conforme role).
- Escolas: apenas quem tem `schools.*`.

### Professor
- Vê Livros (e Sites) e pode **Ativar/Desativar**.
- Não cria/edita conteúdo completo (sem `books.update` / `sites.update`).

## Tarefas frequentes

### Cadastrar livro
Catálogo → Livros → **Novo livro** → preencher → salvar.

### Cadastrar Site
Site → Sites → **Novo site** → autor/categorias/capa/arquivo.  
Guia detalhado: `docs/superpowers/guides/2026-08-06-criacao-de-sites.md`

### Editar leitor (nome/email/telefone)
Comunidade → Usuários → **Editar** (linha ou detalhe) → Salvar perfil.

### Moderar comentário
Comunidade → Comentários **ou** Site → Comentários → Ocultar/Excluir.

### Trocar perfil de um membro da equipe
Sistema → Equipe / Perfis (conforme permissões).

## Operação de infraestrutura (suporte N2)

| Sintoma | Checagem |
|---------|----------|
| Tela branca / 502 | `docker compose ps`; logs backend |
| Login 401 | Usuário/senha; seed; JWT |
| Capas quebradas | `legacy-assets/images`; URL pública |
| App Flutter não lista livros | Host aponta para Kotlin? `/api.php` retorna JSON? |
| Permissão negada | Role do usuário; menu some se sem perm |

## Canais de suporte (sugeridos)

1. Operador: screenshot + rota + horário.
2. N2: logs `docker compose logs --tail=100 backend`.
3. N3: issue no GitHub do repo + commit/sha do deploy.

## Não fazer

- Commitar `.env` com segredos.
- Apagar volume MySQL sem backup.
- Expor `:8080` publicamente se a política for só via `:5173`/HTTPS.
