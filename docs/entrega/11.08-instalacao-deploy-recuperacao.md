# 11.8 — Instalação, ambiente, deploy e recuperação

## Ambientes

| Ambiente | Uso |
|----------|-----|
| Local (dev) | Docker Compose ou Gradle + Vite; MySQL `adm_libare` |
| VPS | ` /opt/adm-libares-new `, Docker Compose |
| Produção painel | https://admin.alenxandriaglobaltec.com |

## Instalação local (resumo)

```powershell
# Na raiz do repo
docker compose up -d --build
# Frontend: http://localhost:5173
# Health:   http://localhost:5173/actuator/health
```

Senhas/DB: ver `docker-compose.yml` e `scripts/local/dev.local.ps1`.

Assets: montar `legacy-assets/images` e `uploads` (ou dump + cópia do PHP).

## Deploy VPS (padrão)

Script oficial:

```bash
cd /opt/adm-libares-new
PUBLIC_BASE_URL=https://admin.alenxandriaglobaltec.com bash scripts/deploy/deploy-vps.sh
```

O script:
1. `git fetch` + `reset --hard origin/main`
2. Garante pastas `legacy-assets`
3. `docker compose build --no-cache backend frontend`
4. `up -d --force-recreate`
5. Aguarda health UP (até 120s)

Domínio/TLS: `scripts/deploy/setup-domain-vps.sh` + conf Nginx host.

## Variáveis críticas

| Variável | Função |
|----------|--------|
| `LEGACY_PUBLIC_BASE_URL` | URLs absolutas de assets nas APIs |
| `LEGACY_ASSETS_HOST_PATH` / `LEGACY_ASSETS_ROOT` | Pasta images/uploads |
| `JWT_SECRET` | Assinatura JWT |
| `CORS_ALLOWED_ORIGIN_PATTERNS` | Origins permitidas |
| `DB_*` | Conexão MySQL |

## Recuperação

| Problema | Ação |
|----------|------|
| Backend não sobe / Flyway failed | `bash scripts/deploy/repair-flyway-vps.sh` |
| Health DOWN | `scripts/deploy/diagnose-backend-vps.sh` |
| Sites/API | `diagnose-sites-vps.sh` / `diagnose-users-vps.sh` |
| Imagens 404 | Conferir volume `legacy-assets` e permissões RW |
| `/api.php` retorna HTML | Rebuild **frontend** (nginx.conf na imagem); commit `0339585+` |
| Rollback de código | `git reset --hard <sha>` + rebuild compose |
| Rollback de dados | Backup MySQL volume / dump antes de import |

## Backup recomendado

- Volume Docker `mysql_data`
- Pasta `legacy-assets`
- Arquivo `.env` da VPS (sem commit de segredos)
