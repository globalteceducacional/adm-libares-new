## Visão em uma frase

Substituímos o painel PHP monolítico por um **admin React + API Kotlin (Spring Boot)** multi-tenant com RBAC, catálogo ebook, módulo Site, auditoria, espelho das APIs do app leitor e deploy em VPS com Docker.

## Stack

| Camada | Tecnologia |
|--------|------------|
| Backend | Kotlin, Spring Boot 3, JPA/JDBC, Flyway, JWT |
| Frontend | React 18, Vite, TypeScript, React Query, Framer Motion |
| Banco | MySQL 8 (`APP_DATA_MODE=legacy` em produção) |
| Infra | Docker Compose, Nginx (container + host), VPS Hostinger |
| Apps clientes | Flutter ebook/Site (host apontando para espelhos `.php`) |
