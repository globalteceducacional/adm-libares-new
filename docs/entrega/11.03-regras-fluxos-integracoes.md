# 11.3 — Regras de negócio, fluxos e integrações

## Regras de negócio principais

### Multi-tenant
- **Escola** = tenant (`school_id`).
- Uma escola possui **N acervos**.
- Livro ↔ acervo é N:N **somente entre acervos da mesma escola**.
- Leitor (`tbl_users`) pertence a **uma escola**; acervo opcional.
- Admin do painel: escola fixa **ou** Super Admin global.

### Catálogo ebook
- Livro exige autor, ≥1 categoria, ≥1 acervo, título, descrição; capa obrigatória no create.
- `fileType`: `server_url` | `local` (upload para storage legado).
- Soft-delete / status `"0"`|`"1"` conforme tela; professor pode só toggle status.

### Usuários do app
- Create: nome, email, senha (≥6), telefone, acervo, status.
- Update perfil: nome, email, telefone (`PUT /api/v1/users/{id}`); **não** altera senha/foto/acervo/status nesse endpoint.
- Email único case-insensitive (excluindo o próprio id no update).
- Equipe (`admin-users`) ≠ leitores (`users`) — menus e APIs separados.

### Módulo Site
- Global (sem escola/acervo), como o PHP legado.
- Create Site: categorias ≥1, autor, título, descrição, capa, arquivo/URL.
- Delete Site **não** toca `tbl_books` / comentários do ebook.

### Senhas do leitor
- Login espelho: plaintext/Argon2 → upgrade para **BCrypt** no sucesso.
- Register/update: senha sempre hasheada.
- Forgot-password: **não** envia senha em claro (melhoria vs PHP).

## Fluxos principais

```
Operador → Login /api/v1/auth/login → JWT
         → Menu filtrado por permissions
         → CRUD /api/v1/... → Policy + tenant → MySQL legado
         → Assets /legacy/assets/...

Flutter  → /user_login_api.php | /api.php | /api_sites.php
         → modules/reader | modules/site/reader
         → Envelope EBOOK_APP | Galileu
```

### Fluxo criar livro (resumo)
1. Novo livro → FormModal  
2. Upload capa/arquivo (se local)  
3. `POST /api/v1/books`  
4. Invalidate React Query → lista atualizada  

### Fluxo login leitor
1. App chama `user_login_api.php`  
2. Valida senha (upgrade se necessário)  
3. Atualiza `tbl_active_log`  
4. Retorna payload legado  

## Integrações

| Integração | Tipo | Contrato |
|------------|------|----------|
| Painel React ↔ Spring | REST JSON JWT | `/api/v1/**` |
| Flutter ebook ↔ Spring | Espelho PHP | `/api.php`, `/user_*.php` |
| Flutter Site ↔ Spring | Espelho PHP | `/api_sites.php` (Galileu) |
| Assets | Arquivos | `/legacy/assets/images|uploads` |
| Ebook legado remoto | Fallback imagens | `VITE_LEGACY_REMOTE_IMAGES_BASE_URL` |
| Swagger | OpenAPI | `/swagger-ui.html` (JWT admin) |
